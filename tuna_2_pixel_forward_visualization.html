Tuna2PixelModel.forward(batch) — 训练入口 (Wrapper Level)

这是 Hydra-instantiable 的 wrapper，接收 DataLoader 输出的 batch dict，协调整个前向过程。

Step 1 解包 Batch Dict

text_tokens  = batch["text_tokens"]     # [B, max_seq_len]
text_labels  = batch["text_labels"]     # [B, max_seq_len]
pixel_values = batch["images"]          # [B, 3, H, W] or [B, N, 3, H, W]
pixel_v_low  = batch.get("images_clip")   # [B, 3, 384, 384]
text_masks   = batch["text_masks"]       # [B, max_seq_len] Bool
image_masks  = batch["image_masks"]      # [B, max_seq_len] Bool
mod_pos      = batch["modality_positions"] # [B, num_imgs, 2]
data_type    = batch["data_type"]        # ["t2i", "mmu", "edit_interleaved", ...]

Step 2 处理 Interleaved 数据

若 data_type[0] == "mmu_interleaved" 或 "edit_interleaved": pixel_values 从 [B, N, 3, H, W] reshape 为 [B*N, 3, H, W]， data_type 复制 N 份。每张子图独立参与 JiT 噪声调度。

Step 3 prepare_latents_and_labels (JiT 风格)

data_typemax_t0含义
t2i / t2i_cond / t2i_editNone随机采样 t（全噪声范围）
edit_interleaved, i%2==0self.und_max_t0条件图 (raw image)：限制噪声量
edit_interleaved, i%2==1None目标图 (target)：完全加噪
mmu / mmu_vid / mmu_interleavedself.und_max_t0 / 1.0-noise_lvl理解任务：轻微噪声或干净图
z_t = t * x + (1-t) * noise — 直接对像素加噪，不经过 VAE latent space。
对 mmu 任务且 und_max_t0==1.0 时，image_masks 被清零（干净图没有 flow loss）

Step 4 prepare_clean_image_embeds

images_clip (低分辨率版本) → 同一个 SimplePatchEmbedding → clean_image_embeds [B, N_clip_patches, hidden_size]
这些 embedding 会在 inner forward 中替换掉 text_tokens embedding 序列中图像位置处的 embedding， 作为重建条件（reconstruction conditioning）。

Step 5 create_attention_mask

根据 attention_backend:
  • sdpa: omni_attn_mask_naive() → attention_mask [B, 1, S, S], diffhead_mask=None
  • flexattention: omni_attn_mask_flexattention() → BlockMask (LLM + DiffHead 各一个)
Omni Attention: 图像 token ↔ 图像 token, 文本 ↔ 文本, 图像↔文本, 全部双向可见。

Step 6 self.tuna_model(...) → Inner Forward

见 "Inner forward()" 标签页的详细分解

Step 7 组装 Total Loss

total_loss = flow_coeff * loss_flow + ntp_coeff * loss_ntp
if use_disp: total_loss += 0.25 * loss_disp
返回 dict: {"loss", "loss_ntp", "loss_flow", "loss_disp", "logits", "recons_images"}

Tuna2Pixel.forward() — Inner Model 逐阶段详解

Phase 1 Token Embedding + Clean Image Conditioning

# 1a. 文本 Token → Embedding
input_embeds = self.tuna.model.embed_tokens(text_tokens)  # [B, S, D_llm]

# 1b. 替换图像区 embedding 为 clean_image_embeds（重建条件）
if clean_image_embeds != None:
    for i:  # 遍历每个 batch
        img_offset = modality_positions[i][0][0]
        # 在图像 token 前 clean_seq_len+1 个位置处替换
        input_embeds[i, replace_start:replace_start+clean_seq_len, :] = clean_image_embeds[i]

Phase 2 _prepare_embeds(image_latents, t)

2a. Patchify 图像

# image_latents: [B, C, T, H, W]
image_embeds = _patchify_5d(
    image_latents.to(dtype),
    self.vision_encoder,  # SimplePatchEmbedding
    reshape_frame_to_batch_dim,
)
# → [B*T, (H/p)*(W/p), hidden_size]

2b. 时间步 Embedding

# t: [B*n_imgs] 标量时间步
time_embeds = self.time_embed(t, dtype)
# t → sinusoidal(t, 256) → MLP → [B*n_imgs, D_diff]

2c. Aspect Ratio Embedding (可选)

if add_aspect_ratio_embeds:
    height_embeds = self.aspect_ratio_embed(H_patches, dtype)
    width_embeds  = self.aspect_ratio_embed(W_patches, dtype)
    # → [B, D_diff] 各一个

2d. 3D RoPE 构建

rope_3d = build_rope(
    latent_shape=[T, H, W],
    patch_size=16,
    attention_head_dim=64,
)
# → [T*Hp*Wp, Dh, 2, 2]

Phase 3 _prepare_input — 将图像特征写入序列

视觉 token 格式:
BOI height_emb width_emb time_emb img_emb_0 img_emb_1 ··· img_emb_K-3 EOI
配置offset+0offset+1offset+2offset+3..+length-1
add_time_embeds + add_aspect_ratio_embeds height_embwidth_embtime_embimage patch embeds (length-3个)
add_time_embeds only time_embimage patch embeds (length-1个)
neither image patch embeds (length个, 直接覆盖)
同时构造 new_image_labels: 将 ground-truth 像素值 image_labels 按照相同的 patch 布局填入 [B, S, patch_size²×C] 形状的标签张量中，仅在图像 token 位置有非零值。

Phase 4 Qwen2.5 LLM Forward

outputs = self.tuna(
    inputs_embeds=input_embeds,        # [B, S, D_llm] — 已融合文本+图像+时间+AR
    attention_mask=attention_mask,     # Omni attention mask
    output_hidden_states=True,
)
logits = outputs["logits"]                # [B, S, vocab_size]
last_hidden = outputs["hidden_states"][-1]  # [B, S, D_llm]
关键: Qwen2.5 以全序列双向 attention 方式处理混合模态序列。 文本位置的 1D RoPE 和图像位置的 3D RoPE 通过 apply_rope_image3d_text1d 分别应用。

Phase 5 Diffusion Head → x0_pred

# 5a. 可选投影
if hidden_size != D_llm:
    last_hidden = self.diff_proj(last_hidden)  # → [B, S, hidden_size]

# 5b. N 层 ModulatedAttentionBlock
for layer in self.diffusion_head_a:  # N = flow_head_num = 10
    last_hidden = layer(
        hidden_states=last_hidden,
        adaln_input=time_embeds,       # 时间条件 → shift/scale/gate
        attention_mask=diffhead_attention_mask,
        position_ids=position_ids,
        rope_3d=rope_3d,               # 3D RoPE for image positions
        modality_positions=modality_positions,
    )[0]

# 5c. FinalLayer: Norm + adaLN + Linear → x0 prediction
x0_pred = self.diffusion_head_b(last_hidden, time_embeds, modality_positions)
# → [B, S, patch_size² × C]  (C = image_latent_dim = 16)

Phase 6 分支：训练 vs 推理

训练路径 (text_labels 和 image_labels 都存在)

loss_ntp = next_token_prediction(logits, text_labels, vocab_size)
# CrossEntropy(logits[:,:-1], labels[:,1:], ignore=-100)

loss_flow = jit_x0_prediction_loss(
    x0_pred, new_image_labels, t, image_masks
)
# MSE(x0_pred, target) * 1/(1-t)² * image_masks

loss_disp = disp_loss(act[-1])  # (可选) InfoNCE-L2 多样性 loss

return logits, loss_ntp, loss_flow, loss_disp

推理路径 (无 labels)

# 1. 按 modality_positions 切片 x0_pred
for (offset, length) in modality_positions:
    x0_pred_.append(x0_pred[i, offset:offset+length])

# 2. 移除 time/AR embedding tokens
if add_time_embeds and add_aspect_ratio_embeds:
    x0_pred_ = x0_pred_[:, 3:, :]  # 移除 H_emb, W_emb, T_emb

# 3. Unpatchify
x0_pred_ = self.unpatchify(x0_pred_, h_, w_, T=T)
# [N, T, p²*C] → [N, C, T, H*p, W*p]

return logits, x0_pred_

SimplePatchEmbedding — Conv2d 像素 Patchifier

输入 → 输出

pixel_values [B, 3, H, W] (RGB in [-1, 1])
↓ Conv2d(kernel=patch_size=2, stride=2, out_ch=hidden_size)
→ [B, hidden_size, H/2, W/2]
↓ Flatten + Transpose
→ [B, (H/2)*(W/2), hidden_size]
↓ RMSNorm(hidden_size)
→ [B, num_patches, hidden_size] (最终输出)

_patchify_5d — 5D 图像 → Patch Embedding 桥接

image_latents [B, C, T, H, W]
  • reshape_frame_to_batch_dim=True: reshape → [B*T, C, H, W] → patch_embed → [B*T, N_patches, D]
  • reshape_frame_to_batch_dim=False: 逐帧 patch_embed → concat → [B, N_patches*T, D]

TimestepEmbedder — 时间步正弦编码

t → time_embeds

t [N] 标量时间步 (0~1)
↓ timestep_embedding(t, dim=256, max_period=10000)
→ 正弦编码: [cos(w₀*t), sin(w₀*t), cos(w₁*t), sin(w₁*t), ...]
→ [N, 256]
↓ MLP: Linear(256→D) → SiLU → Linear(D→D)
→ [N, D] time_embeds
频率: w_k = exp(-k * log(10000) / 128), k = 0..127

build_rope — 3D 旋转位置编码

维度分配说明
T (时间)attention_head_dim // 4 = 16视频帧维度
H (高度)attention_head_dim // 8 * 3 = 24patch 高度维度
W (宽度)attention_head_dim // 8 * 3 = 24patch 宽度维度
为 latent 空间中的 (T, H/patch, W/patch) 网格的每个位置生成 3D RoPE 旋转矩阵 [T*Hp*Wp, Dh, 2, 2]

Diffusion Head 详细结构

ModulatedAttentionBlock (×10 layers)

adaLN 自适应层归一化调制

time_embeds [B*n_imgs, D]
↓ SiLU → Linear(D → 6×D)
→ shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp

关键: 调制参数只应用到图像 token 位置（由 modality_positions 确定）。 文本位置的 hidden states 保持不变（shift=0, scale=0, gate=1）。

Self-Attn + MLP（带调制）

Attention Block:
h = RMSNorm(h)
h = h * (1+scale_msa) + shift_msa
h = SelfAttention(h, rope_3d, omni_mask)
h = residual + gate_msa * h

MLP Block:
h = RMSNorm(h)
h = h * (1+scale_mlp) + shift_mlp
h = MLP(h) ← gate_proj/up_proj/down_proj
h = residual + gate_mlp * h

Self-Attention 中的 3D RoPE 应用

在 SdpaAttention.forward() 中:
  1. Q, K 投影 → reshape 为 [B, num_heads, S, head_dim]
  2. 通过 apply_rope_image3d_text1d: 文本位置用 1D RoPE (cos/sin), 图像位置用 3D RoPE
  3. 图像 token: skip time_embedding token (offset+0), 从 offset+1 开始应用 3D RoPE
  4. SDPA / FlexAttention 计算 attention weights
  5. GQA: key_value_heads=8, query_heads=24, repeat_kv 扩展

FinalLayer → x0 预测

time_embeds → SiLU → Linear(D→2D) → shift, scale
调制仅应用于图像 token 位置的 hidden states
RMSNorm(h) * (1+scale) + shift → Linear(D → patch_size² × C)
→ x0_pred [B, S, patch_size² × C]
(patch_size=2, C=image_latent_dim=16 → 2²×16 = 64 维输出)

Masked Image (DeTok 集成)

在 _prepare_embeds 中，当 enable_mask_token=True 且处于训练模式时:
  • 随机选取 masked_image_ratio_min ~ masked_image_ratio 比例的 patch
  • 将这些 patch 的 embedding 替换为可学习的 self.mask_token [1, 1, hidden_size]
  • 模型被训练从被 mask 的 patch embedding 中重建完整图像

Loss 计算全景

Loss函数公式作用域
loss_ntp next_token_prediction(logits, text_labels, vocab_size) CrossEntropy(logits[:,:-1].view(-1,V), labels[:,1:].view(-1), ignore=-100) 仅 text_labels ≠ -100 的 token 位置
loss_flow jit_x0_prediction_loss(x0_pred, new_image_labels, t, image_masks) MSE(x0_pred, x0_target) × 1/(1-t)² × image_masks 仅 image_masks=1 的 token 位置
loss_disp disp_loss(act[-1]) InfoNCE-L2: log(mean(exp(-||z_i - z_j||² / D))) 最后一层 diff head 的激活 (pairwise distance)

Total Loss

total_loss = flow_coeff * loss_flow + ntp_coeff * loss_ntp  # 默认均为 1.0
if use_disp: total_loss += 0.25 * loss_disp

JiT x0 Prediction Loss 权重分析

loss = MSE(x0_pred, x0_target) / (1-t)²
  • t ≈ 1 (几乎干净): 1/(1-t)² 很大 → 对近干净图像的预测误差惩罚更重
  • t ≈ 0 (纯噪声): 1/(1-t)² ≈ 1 → 标准 MSE 权重
  • clamp_min=5e-2 避免除零
  • image_masks 确保只计算图像 token 位置的 loss
  • EDIT 任务: image_masks 仅在 target 图像段为 1，raw 图像段 loss=0
  • MMU 任务 und_max_t0=1.0: image_masks 被清零，loss_flow=0

各任务类型 Loss 对照

data_typeloss_ntploss_flow说明
t2i 0 (text_labels 全部 -100) ✅ (image_masks=1) 纯扩散 loss，文本仅作为条件
mmu ✅ (response tokens 有真实 label) 0 或轻微 (取决于 mmu_noise) 主要训练 LM head，可选轻微去噪
edit_interleaved 0 (全部 -100) ✅ (仅 target 图像) raw 图像 image_masks=0，target 图像 image_masks=1
mmu_interleaved ✅ 0 (und_max_t0=1.0 时 masks=0) 多图理解任务
mmu_text ✅ 0 (image_latents=None) 纯文本对话

推理路径: x0_pred → 最终图像

推理时无 loss 计算，直接输出预测的干净图像:
  1. 从 x0_pred [B, S, p²*C] 中按 modality_positions 切片出图像区域 → [N, L, p²*C]
  2. 若 add_time_embeds + add_aspect_ratio_embeds: 移除前 3 个 token (H/W/T emb)
  3. 若 add_time_embeds only: 移除前 1 个 token (T emb)
  4. unpatchify: [N, T, p²*C] → [N, C, T, Hp*p, Wp*p]
  5. 即 patch_size=2 时: [N, p²*C, T, Hp, Wp] → reshape → [N, C, T, Hp*2, Wp*2]
